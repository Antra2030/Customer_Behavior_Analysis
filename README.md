# Customer_Behavior_Analysis
## 1. Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, understand customer preferences, and generate meaningful business insights.

The project follows an end-to-end data analytics workflow, starting from data loading and preprocessing in Python to exploratory data analysis (EDA), SQL-based analysis using Neon PostgreSQL, and interactive dashboard development in Power BI.

A final analytical report and presentation were also created to communicate key findings and business insights.

## 2. Dataset

* **Dataset:** Customer Shopping Behavior Dataset
* **Format:** CSV
* **Description:** Contains customer-related information, including demographics, purchased products, purchase amounts, discounts, shipping preferences, and customer reviews.
* **Purpose:** To understand customer purchasing patterns and identify factors influencing shopping behavior.

## 4. Project Workflow

The project was completed through the following steps:

### Step 1: Data Loading

* Imported the dataset into a Python environment.
* Loaded the CSV file using Pandas.
* Examined the dataset structure, dimensions, and data types.

### Step 2: Exploratory Data Analysis (EDA)

* Analyzed numerical and categorical variables.
* Identified purchasing patterns and customer preferences.
* Examined distributions, relationships, and trends.
* Used visualizations to understand the data.

### Step 3: Data Cleaning

* Checked for missing and duplicate values.
* Handled data inconsistencies.
* Corrected data types where required.
* Prepared the cleaned dataset for further analysis.

### Step 4: SQL Analysis using Neon PostgreSQL

* Connected the dataset to a Neon PostgreSQL database.
* Performed business-oriented analysis using SQL queries.
* Used aggregate functions, GROUP BY, ORDER BY, CASE statements, and subqueries.
* Extracted insights related to customer spending, discounts, product ratings, and shipping preferences.

### Step 5: Power BI Dashboard

* Connected Power BI to the Neon PostgreSQL database.
* Created an interactive dashboard to visualize important business metrics.
* Used charts, cards, and other visual elements to present analytical findings.

### Step 6: Reporting and Presentation

* Prepared a project report documenting the analysis and findings.
* Created a PowerPoint presentation using Gamma AI.
* Organized the findings into a structured format for clear communication.

## 7. How to Run the Project

Follow these steps to explore the project:

**1. Clone the repository**

```bash
git clone <your-repository-link>
```

**2. Install the required Python libraries**

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

**3. Run the Python Notebook**

* Open the `.ipynb` file in Jupyter Notebook or Kaggle.
* Execute the cells to perform data loading, cleaning, and EDA.

**4. Run SQL Queries**

* Access the SQL query file: `customer_behavior_sql_queries.sql`.
* Connect to your Neon PostgreSQL database.
* Execute the queries to reproduce the SQL analysis.

**5. Explore the Power BI Dashboard**

* Open the `.pbix` file using Power BI Desktop.
* Configure your database connection if required.
* Refresh the data to explore the dashboard.
